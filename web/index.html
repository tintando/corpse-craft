PopCraft

A 2011 Whirled game, rebuilt from source with a toolchain that no longer exists, running here under Ruffle. The corpse-craft repository is how it was put back together.

Ruffle did not load, so there is nothing to play here.

It needs WebAssembly, which every current browser has. A content blocker or a very old browser is the usual cause.

Progress is saved in this browser, under this page's address. Clearing site data for this domain resets the game, and a private window forgets it when you close the tab.

Click the stage first: browsers will not start the sound until the page has been interacted with.
